# Unit tests touch nothing outside the unit

A gate blocks file-system, subprocess, and network calls in a unit test, and it times the whole unit run against the 10-second budget.

- The gate allows the file access that pytest makes for its cache and imports.
- The gate blocks temp files, so a unit test uses a fake and not `tmp_path`.
- Real file access belongs in the integration suite.
