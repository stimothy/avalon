# No junk-drawer directory names

A gate matches directory names at any depth, in any letter case.

This repo authors every git-tracked path except `.claude/` and the plan folders that `PLAN_FOLDERS` in `devtools/gates/skip_list.py` lists. A change to `PLAN_FOLDERS` changes the scope of this law and goes to a round table before it merges.
