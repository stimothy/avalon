# Coverage floor

A gate fails when line coverage of the authored Python is below 80%.

This repo authors every git-tracked path except `.claude/` and the plan folders that `PLAN_FOLDERS` in `devtools/gates/skip_list.py` lists. A change to `PLAN_FOLDERS` changes the scope of this law and goes to a round table before it merges. The tests directory is excluded from the measure.
