# Checks with no finding

A gate runs the format check, the linter, and the type checker on the authored Python. It fails on any finding.

A check is a rule of one of the three tools. No check is turned off outside `pyproject.toml`. A gate fails on a comment in the authored Python that turns a check off. These comments are covered:

- `# noqa`
- `# ruff: noqa`
- `# fmt: off`
- `# fmt: skip`
- `# type: ignore`
- `# mypy:` inline settings

`# pragma: no cover` is out of scope, because coverage is not one of the three tools.

A file such as `ruff.toml` or `mypy.ini` that turns a check off also breaks this law. A reviewer checks such files, because the gate reads only comments.
